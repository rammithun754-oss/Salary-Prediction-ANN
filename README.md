# 💰 Salary Prediction using ANN (PyTorch Regression)

A simple Artificial Neural Network (ANN) regression project built using PyTorch to predict salary based on years of experience.

This project demonstrates:

- ANN fundamentals
- Regression using Deep Learning
- Forward propagation
- Backpropagation
- Loss optimization
- PyTorch basics

---

# 🚀 Features

✅ ANN regression model  
✅ Salary prediction based on experience  
✅ Mean Squared Error loss  
✅ PyTorch implementation  
✅ Beginner-friendly AI project  
✅ Neural network training pipeline

---

# 🧠 Model Architecture

The Artificial Neural Network contains:

- Input Layer → 1 feature
- Hidden Layer → 4 neurons
- ReLU Activation
- Output Layer → 1 salary prediction

---

# 📂 Dataset

The dataset contains:

- Years of experience
- Corresponding salary values

Example:

| Experience | Salary |
|---|---|
| 1 | 25 |
| 5 | 45 |
| 10 | 70 |

Salary values are represented in thousands.
